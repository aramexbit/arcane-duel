ARCANE DUEL: WARRIORS OF THE LOST REALM is a turn-based artillery fantasy game for the desktop browser — aim with parabolic physics and wind, battle AI across 3 arenas in a 6-battle campaign, or duel a friend in local multiplayer. Pick from 3 original heroes (KAIRO, NYX, BRONT), unlock 12 weapons and cosmetic skins, and play fully offline.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser.
